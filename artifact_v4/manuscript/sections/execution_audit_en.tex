\section{Executable Routing and the Development Audit}
The structural study uses a new frozen protocol and fresh training, validation, planning and test streams. An earlier independent implementation is retained in the versioned research archive. Its six individual known-structure routing contrasts did not establish a beneficial effect after multiplicity correction; its descriptive equal-process normalized difference was $-0.090$ with supplied structure and $0.001$ with discovered structure. Those outcomes are not pooled with the new primary comparisons.

An analytic audit identified two executor defects before the new freeze. Two trees with visible language $(BD)^+$ placed the return decision at different points. Under a fixed return probability $0.2$, the old executor produced 1.250 versus 2.027 visits per case; halving the return probability produced 1.1085 versus an unchanged 2.027. The test contains 2000 independently generated cases. Normalizing the shared continuation moves the choice to its observable decision point and makes the two trajectory arrays exactly equal, both with and without intervention. The expected visit counts are $1/0.8$ and $1/0.9$. A separate guarded-XOR test found 999 violations among 2000 cases because fitted simulation ignored explicit class guards. The corrected executor has zero violations. These tests establish execution properties, not policy-cost effect sizes.

A separate 92-run audit covers every process, feedback world and intervention type. Truth-generator samples, lifecycle records, completions and activation times are identical before and after correction. Generating equations, capacities, costs, arrival conditions and load scales are unchanged. Technical pilots check all six discovered structures and equivalence of known/discovered planning scores, and are excluded from inference.

The discovery wrapper compares standard Inductive Miner with a candidate that prioritizes its existing strict-loop fallback and infers deterministic observed attribute guards. It admits candidates only when all training traces fit optimal alignments and execution passes the compiler checks, then maximizes training token-replay precision. Global alignment fitness can be slightly below one because silent transitions have nonzero alignment cost; admission uses the percentage of fitting traces. The candidate does not receive the reference tree. Visible-language equivalence is checked only afterward as a synthetic evaluation diagnostic. The complete candidate models, guards, conformance outputs and preparation receipts are retained.

The executed implementation bounds each model at 30 visible labels, 62 places, 120 transitions and 32 resource pools, with binary observed class and process attributes. It rejects unsupported choices and unsafe markings. These are implementation bounds, not an empirical scalability claim.

An additional technical check uses only the excluded pilots. The campaign's shared configuration object carries truth fields, although fitted preparation does not use them. Replacing the truth tree and generating coefficients, and removing control-flow topology from behavioral fitting, leaves the fitted parameters, selected discovered structure and fitted execution exactly unchanged for all six pilots. Resource maps, candidate return sites and observation mappings remain supplied engineering inputs.
